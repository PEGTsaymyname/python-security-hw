# Анализ и визуализация событий информационной безопасности

Домашнее задание по теме «Python для аналитиков ИБ: API и анализ данных».

## Описание проекта
Скрипт загружает набор событий информационной безопасности из файла `events.json`, анализирует их распределение по типам угроз (поле `signature`) и строит столбчатую диаграмму.

## Структура репозитория
* `main.py` — основной скрипт для обработки данных и построения графика *(замените на имя вашего файла, если оно отличается)*
* `events.json` — исходный файл с данными о событиях ИБ

## Установка и запуск

1. Установите необходимые библиотеки:
```bash
pip install pandas matplotlib seaborn
```

2. Запустите скрипт:
```bash
python main.py
```

## Результат
После запуска скрипт выводит в консоль статистику по количеству событий каждого типа и открывает окно со столбчатой диаграммой распределения (`Seaborn` / `Matplotlib`).
